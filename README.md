# dsh-preset-composer

English | [简体中文](README.zh.md)

A visual editor for DSH agent presets. It adds a **Preset composer** section to Settings, next to Agent presets.

![icon](assets/icon-180.png)

## What it does

- Lists every agent preset, shipped and custom, and shows its plugin rows, parameters and `!!js` expressions read-only.
- Edits a preset as a tree: add, remove, reorder and drag plugin rows, toggle them on or off, and put rows inside `cordis:group` groups.
- Opens a parameter dialog for a plugin row. Fields come from the installed DSH `docs/config-catalog.md` (144 modules in DSH 0.2.2-rc.5) with defaults from the config schema. Plugins missing from the catalog fall back to raw JSON.
- Groups the plugin library by purpose (tools, prompt, models, subagents, sessions, permissions, shell, host services, interface, experimental) and searches by name, title and description.
- Creates and duplicates custom presets. Saving a shipped preset writes an override through the `configEditor` service; Reset removes it.

Preset changes apply to new sessions. Existing sessions keep the preset they started with.

## Install

Requires DSH 0.2.x. Download `dsh-preset-composer.tgz` from the latest release, then:

```sh
dsh plugin --profile <name> add ./dsh-preset-composer.tgz
```

Or from source: `dsh plugin --profile <name> add github:DAnonyvinciT/dsh-preset-composer` (pnpm needs `allowBuilds` approval only if a build script exists; this package has none).

Restart DSH after installing.

## Parts

- `lib/index.js`: Host plugin. Serves `GET /api/preset-composer/state` and `POST /api/preset-composer/{save,delete,reset}`.
- `lib/store.js`: Host plugin (`dsh-preset-composer/store`). Registers valid custom presets from its own `presets` config with the `agentPresets` registry.
- `lib/model.js`: validation, normalization, revisions and the plugin palette.
- `lib/catalog.js`: parses the installed `config-catalog.md` into per-plugin field lists.
- `lib/defaults.json`: parameter defaults generated by `scripts/gen-defaults.mjs` from `dsh web --dump-config-schema`. Regenerate after upgrading DSH.
- `client.js`: the Settings section (React, `dpc-` prefixed styles, host theme tokens).

## Develop

```sh
node --test test/
node --check client.js lib/*.js
```

## Limits

- The read-only view shows configuration values as stored, including any secrets in plain text.
- Parameter defaults are missing for some modules; those fields show no default.
- Preset editing needs an editable profile (the plugin must be installed in the profile root).
